---
title: Быстрый старт
description: Как начать отправлять события session_start и session_end без SDK.
---

appmetrica.online принимает системные события приложений по HTTP. SDK не нужен: клиент сам отправляет
`session_start` при запуске и `session_end` при уходе в фон.

## 1. Создайте приложение

В портфеле нажмите «Создать приложение», выберите платформу и часовой пояс. На экране «Интеграция»
появится write-ключ `pk_…` и готовые сниппеты.

## 2. Отправьте первый батч

```bash
curl -X POST https://i.appmetrica.online/v1/events \
  -H "Content-Type: application/json" \
  -H "X-App-Key: pk_…" \
  -d '{"sent_at":"2026-10-14T09:00:00Z","context":{"platform":"ios"},"events":[…]}'
```

Ответ `200` приходит только после записи в хранилище. Поле `accepted` — число принятых событий,
`rejected` — отклонённые с кодом причины.

## 3. Проверьте данные

На вкладке «Интеграция» видны последние события и ошибки, на вкладке «Аудитория» — DAU и новые
пользователи.
